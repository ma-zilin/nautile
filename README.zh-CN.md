## 概览

Nautile 是一款面向个人的计划、时间记录与复盘应用，把待办、日程、时间日志和 AI 辅助分析放在同一套数据里，减少在多个工具之间来回切换。它希望保持小而专注，不在本地运行大模型；云端 AI 计划使用 DeepSeek 官方接口。项目计划以开源方式发布。

## 计划中的功能（首版范围）

以下为首版范围。仅“当前状态”中描述的待办/设置子集已实现，其余为计划内容，不构成验收结果。

**计划与组织**

- 轻量 GTD 组织含五个任务位置（收件箱、下一步行动、等待中、将来／也许、已结束）与独立项目容器/视图；日程统一从一级日程入口访问，GTD 不设“日历”位置；通过 GTD 左抽屉或主页面边界拉动切换清单。
- 待办标签、完成／放弃／删除操作，以及按完成与放弃数量统计的完成率。
- 待办提醒默认关闭，可在待办中手动设置。
- 按项目分组的标准待办页；每个 GTD 模块可切换分类与排序。

**日程**

- 内置日历，提供日、三天、周视图，并可按来源查看课程表、课程表与普通日程合并、仅普通日程。
- 日程标签筛选；导入课程默认“课程表”标签，未设置时默认“无标签”。
- 从学校教务来源导入真实课程表；技术路径待架构确定，导入前提供预览和校验。重复导入会替换上一次导入生成的全部课程日程，不按重叠范围；手动或 AI 标记为“课程表”的普通日程保留。
- 重复日程支持每天或每周指定星期并设定结束日期；修改与删除支持仅本次、此事件及后续、整个系列三种范围。
- 每条日程可配置多次提醒，并支持时间边界或复盘时间的轻量提醒。

**时间记录**

- 两级分类必填的时间日志，可选关联任务；按时间倒序查看、最新在上，支持补录与编辑，并提供每日分布。
- 点击分类即开始计时；点击计时条上的当前分类即结束并保存。单活动与并行模式互斥，默认并行。
- 按日、月、年或自定义起止日期统计，并包含未追踪时间。

**AI 辅助**

- AI 为全屏页面，顶部有大标题与设置、不设搜索；长按导航中的 AI 入口可快捷输入。单会话共用草稿，不自动附带页面上下文，不支持附件。
- 通过对话查询实际数据、创建或调整日程；每种写操作首次执行时需要确认。
- 分析一段时间内的时间日志与完成情况，并基于这些数据给出下一阶段建议。
- 可查询与分析时间日志，但不能创建、修改或删除；日志写入由我手动完成。
- 分析待办标签占比，说明事务重心。
- 个人偏好经确认后才长期保存。
- DeepSeek API Key 存放在系统安全存储中；AI 会话仅存本地且可清除。

**导航与编辑**

- 底部导航固定四个入口：待办、日程、日志、AI；入口不可隐藏、不可调序，设置从各一级页面顶部进入。
- 详情以半屏展示，修改后逐字段保存；新建需显式创建；条目操作用锚定菜单，选项在底部面板展开。
- 支持 Android 预测性返回：系统返回手势或返回键完成前预览上一页，默认开启，可在设置中关闭；设备不支持时回退普通返回。

## 已知限制

- R5 验证均在 Android 16（API 36）模拟器（`emulator-5554`）执行，尚未在目标真机（vivo X200s / OriginOS 6 / Android 16）上实测。
- 动效观感与物理手势未自动化：220ms 线性完成退场动画流畅度、抽屉/边界拉动/条目滑动/半屏下拉的 1:1 跟手与回弹手感、24h 时间圆盘拨动手感、减少动态效果（`AnimatorDurationScale = 0`）降级、真实 IME 软键盘交互与边缘返回冲突均需真机人工核验。
- 200% 系统字体缩放、TalkBack 朗读走查、Accessibility Scanner 扫描、深色对比度精确数值以及性能指标（帧率/内存/启动耗时）尚未实测。
- AC-N-21 的预测性返回预览组合的是下层页面的一份独立只读实例，不是上一页精确状态的快照，视觉结果仍需真机人工评审。
- 整进程重启后的 UI 恢复未自动化（数据库关闭重开后的持久化已有测试覆盖）。
- 手动排序入口按 `FR-V-03` 暂缓（已存 `manual` 回退 `created`，保留 `manual_order` 字段与 DB v3 结构）；`DatePicker` 日历当前语言为 `en-US`。
- 日程/课表导入、时间日志/计时/统计、AI/个人记忆、标签、提醒、重复、子任务与项目颜色/图标尚未实现；AC-D-07 只覆盖待办创建。需要人工评审的 AC 在本 README 中不构成验收结果。

## 快速开始

Nautile 当前可构建并运行待办/设置切片（截至 R5）；日程、日志、AI 与其余首版功能尚不可用。

### 环境要求

Android 12（API 31）及以上。工程使用 compileSdk 37、targetSdk 36、JDK 17（在仓库外配置）与 Gradle wrapper 9.6.0。

### 安装

执行 `./gradlew assembleDebug` 构建 debug APK（存在仓库外签名文件时可用 `./gradlew assembleRelease`）：

- debug：`app/build/outputs/apk/debug/app-debug.apk`
- release：`app/build/outputs/apk/release/app-release.apk`

使用 `adb install -r app/build/outputs/apk/debug/app-debug.apk` 安装。release 构建从仓库外读取签名配置，缺少时跳过 release 变体。

### 配置

云端 AI 计划只使用 DeepSeek 官方接口，API Key 由使用者自行填写，不在本地运行模型。具体配置格式尚未确定。不要把真实密钥提交到仓库，占位示例：

```text
DEEPSEEK_API_KEY=<在此填写>
```

### 数据库

存储使用 Room 与 KSP（Room 2.8.5、KSP 2.3.14）。数据库 **version 3** 定义 `tasks` 与 `projects`，包含 v1→v2 添加的可空 `tasks.detail` 列（`ALTER TABLE tasks ADD COLUMN detail TEXT`）与 v2→v3 添加的可空 `tasks.manual_order` 列（`ALTER TABLE tasks ADD COLUMN manual_order INTEGER`）。三个 schema（`1.json`、`2.json`、`3.json`）均已提交到 `app/schemas/`。迁移与 DAO 测试在 JVM 与 Android 16 模拟器/设备上执行（见验证记录）。

## 使用

已实现的待办与设置流程：打开待办页，通过左侧 GTD 抽屉或方向锁定边界拉动切换清单；点按前置 Checkbox（220ms 线性退场）或右滑完成任务、左滑放弃任务；点按任务打开与新建同构的下半屏详情（标题/详情与日期/24h 时间圆盘、优先级、项目、清单均编辑/选择即保存）；点按项目可内联编辑名称或通过纯 chevron 图标折叠子任务；顶栏支持实时搜索与视图分类/排序；通过圆形 FAB 新建待办或项目，从右上角入口打开设置。预测返回开关、默认页、上次页面/清单及各清单视图选项均存储在 DataStore。
