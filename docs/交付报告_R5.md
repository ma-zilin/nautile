## 1 目标与 10 项范围

R5 目标：在 R4 终态代码基线 `d5b7a1f` 之上，按确认版需求基线 `docs/需求基线.md` **v2.16**（`docs/需求变更记录.md` 4.26 / 4.27，确认点 `C-36` / `C-37`）与交互动效规格，完成待办域 10 项交互修正、详情与新建统一、日期/24h 时间圆盘及 MD3 框架下对 TickTick 交互与视觉语言的对齐。全程**零新增 Gradle 依赖**、**零 Room Schema 变更**（维持 DB v3）、**不复制任何第三方品牌标识/素材/文案**。

### 1.1 需求基线 v2.16（4.26 / 4.27）落档摘要

- **4.26（`C-36`）**：GTD 左抽屉宽度调整为 `min(max(五项最长标题宽 + 2×24dp, 240dp), 320dp)`；主页面边界拉动增加起手方向锁定与反向越过 0 取消；任务行标题前新增 Checkbox、下方行内显示详情（无则不占行）与截止时间（早于当前时刻 `error` 色高亮且颜色非唯一信息、不自动结项）、Checkbox 点击完成走勾选态→200–250ms 线性淡出/滑出收拢→进入“已结束”（与右滑同路径）、已结项行禁用 Checkbox 与滑动完成；条目滑动方向全局对调为右滑完成（左侧 `ic_check` + “完成” + `primaryContainer`）、左滑放弃（右侧 `ic_close` + “放弃” + `errorContainer`），项目行同步。
- **4.27（`C-37`）**：日期选择日历星期表头不与首排日期重叠；时间仅允许 24h `HH:mm`（0–23 / 0–59 严格校验，非法输入内联报错阻止提交、不静默修正）；日历下方新增“时间”行，点击进入 M3 24h `TimePicker` 圆盘（不新增依赖），支持确认显示与清除，系统返回分层先关圆盘再关日历面板；待办详情改为与新建面板同构（标题/详情编辑即保存、四属性选择即保存），删除旧独立任务详情布局及任务/项目详情头部编辑入口与独立编辑面板（正式**关闭 4.25.4 第 1 项**待确认）；项目详情子任务折叠改用纯 chevron 图标按钮（无文字、带 `contentDescription`）并保留名称内联编辑即保存；在 MD3 下对齐 TickTick 交互与视觉语言，范围外模块不变，手动排序入口继续按 `FR-V-03` 暂缓。
- **覆盖矩阵核对**：基线 6.4 计数不变——正文定义 AC 总数 **120**（6.1—6.3 展开 100 + 6.4 登记 20，其中 15 条基线章节 + 5 条后期增补），历史章节 `4.1—4.25` 零改写，正文旧口径残留 0 条。
