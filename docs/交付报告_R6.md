### 2.2 功能清单（本轮实际交付）

日程：

- 日、三天、周三种视图；周视图固定周一至周日 7 天；视图按钮打开菜单切换，不轮换。
- 顶部日期条：点按选日期、今天快捷、左右滑动不切日期。
- 固定时间网格：小时行高 60dp，日高 = 24 × 小时；无捏合/缩放入口。
- 新建与详情半屏：添加按钮位于导航上方；导航隐藏、草稿保留；字段编辑即保存；取消不生成记录；创建成功原位插入、不跳页、不改筛选。
- 严格 24h `HH:mm` 校验（0—23 / 0—59），非法输入内联报错、阻止提交、不静默修正；日期日历 + 时间行 + 24h 圆盘分层返回；结束必须严格晚于开始，跨天允许。
- 来源三态与空态：“课程表 / 合并 / 仅普通”（基线全称：显示课程表 / 课程表与普通日程合并 / 仅普通日程）；无课程数据时“课程表”为空并显示“课程表暂无日程”，“合并”等价于仅普通。
- 标签字段：仅“课程表 / 无标签”，不改来源；本轮无标签筛选入口。
- 详情显示来源“普通”，不提供来源修改入口；删除有确认且提示不可恢复。

日志：

- 两级分类：父级/子级可增删改；第三级被拒绝并提示；无批量清空；有子级或日志时删除被拒并提示，逐条清理后可删。
- 记录：补录（可跨天、可改分类与起止）、详情编辑即保存、删除；记录按倒序分组；不产生重复记录。
- 计时：点分类快捷入口开始，最近使用优先，“全部分类”常驻；同分类再点只提示；点计时条对应模块结束并保存；无暂停；再次开始生成新记录。
- 并行计时：不同分类可同时运行，每分类最多一段，分别结束；隐藏计时条、切记录/统计、离开页面不结束；墙钟恢复（force-stop 后按开始时刻计算）。
- 计时条：位于导航上方，分类多时内部横滚，导航隐藏时一起隐藏，隐藏后计时继续。
- 模式选择器：标题按钮打开半屏选择器，不直接轮换、不右滑打开；左侧点按记录/统计；退出后恢复今日。
- 统计：日、月、年、自定义范围；均显示同一套饼图、图例与父级汇总；未追踪单独成片；运行中实时计入；标注“含重叠累计”。
- 跨天：一条逻辑记录，统计在 00:00 派生两段分别计入两天；编辑/删除作用于整条。
