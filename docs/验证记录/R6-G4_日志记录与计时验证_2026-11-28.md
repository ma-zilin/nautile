## 4. 失败项（G4-DEF-01，需交回开发）

### 无历史记录时日志页缺少“全部分类”入口（AC-T-21）

- **预期**：基线 AC-T-21“快捷入口优先显示最近使用，并提供‘全部分类’入口”；设计 05 §3.3 规定“全部分类”
  常驻快捷入口末尾，空态下快捷入口与补录仍可用。新安装（已有分类、尚无日志）时，用户应能点“全部分类”
  选择分类并开始计时。
- **实际**：`AcLogT21T22T23UiTest#AC_T_21_all_categories_entry_is_available_without_history` 失败：
  `Expected exactly '1' node but could not find any node that satisfies: (TestTag = 'log_all_categories')`。
  空态文案仍提示“点上方分类开始计时”，但上方没有任何分类入口，只能补录。
- **复现步骤**：
  1. 清空应用数据（或全新安装），在“设置 → 分类管理”建两个分类；
  2. 进入“日志”页，不做任何补录；
  3. 观察快捷入口：只有空态提示与 FAB，没有“全部分类”入口（`log_all_categories` 节点数为 0）；
  4. 点不到任何分类，无法开始计时。
- **事实依据**：`LogScreen` 向 `CategoryQuickEntry` 传入 `state.recentCategories`（由最近日志推导，首次为空）；
  `CategoryQuickEntry` 仅在 `categories.isNotEmpty()` 时追加“全部分类”项。近期使用为空时整行无入口。
- **原因推测**：“全部分类”的显示条件误用了“最近使用列表非空”，而不是“常驻/存在分类”。
- **影响**：AC-T-21 的核心入口“点分类开始计时”在首次使用时不可达；属功能缺陷，需开发修复。
- **测试位置**：`app/src/androidTest/java/io/github/mazilin/nautile/verification/AcLogT21T22T23UiTest.kt`；
  该用例在修复版本上应转绿，不得删除或放宽。
