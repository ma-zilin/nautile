2. 精确还原：把该值改回 `AiMessageId(2)`，`grep` 复核两处均为原值。
3. 绿：同一单测 `OK (1 test)`（`mutation_AI-G4_green_20261128T163303.txt`）。
4. 还原后重新构建并以最终 APK 复跑全量：`OK (377 tests)`。

说明：该变异证明断言对真实流式渲染逻辑敏感、并非空断言；**不是**业务代码变异。业务代码变异未执行，原因是本轮角色边界禁止修改 `app/src/main/**`。
