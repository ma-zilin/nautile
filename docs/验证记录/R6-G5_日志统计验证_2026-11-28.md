## 5. 测试自身错误与纠正（保留原结果）

首轮 JVM 复跑中 `AcStatsPeriodG5Test#AC_L_07_366DayRangeIsSupported` 失败（`EXIT=1`，32 tests / 1 failure）。原因是我把分母断言写成 `toMinutes() == 8784`，而 24h×366 = 8784 **小时** = 527040 分钟；实现值正确。纠正为 `toHours() == 8784` 后同用例转绿，未删除断言、未放宽预期；其余 31 例未变。该失败归类为**测试错误**，不是业务缺陷。
