## 5. 请求体断言（AC-A-12/17）

JVM 断言（真实 `AiRequest`）：

- `systemPrompt == AiSystemPrompt.TEXT`，且包含“无法访问…本地数据”“不要假设当前页面、日期、筛选条件或屏幕上可见的内容”。
- 两轮成功＋一轮失败后发起新请求，`turns` 精确为：
  `USER q1 → ASSISTANT a1 → USER q2 → ASSISTANT a2 → USER q3 → USER q4`；
  **FAILED 的部分文本“半截回复”未进入请求**。
- 序列化 `DeepSeekRequestJson.build(request)` 中：
  `"role"` 数量 = 1 条 system + turns；不含 `"page"/"date"/"filter"/"visibleContent"/"context"` 字段。
- 真实 Room 路径第二轮请求（`AiG3ChatFlowTest.secondTurnRequestContainsOnlyPriorConversationAndFixedPrompt`）同样只含 `USER 第一问、ASSISTANT 第一答、USER 第二问`。

请求不含 Key（`AiRequest` 无 Key 字段；Key 仅在网关 `Authorization` 头临时读取）；Key 存储位置为 `noBackupFilesDir/secrets`，不写 Room/DataStore。

## 6. 重启/重建与清除

`AiG3RestartTest.aiPageRestoresWithoutKeyboardAndClearedConversationStaysCleared`：

1. 点击 AI 入口并写入一轮固定时间消息；
2. 等待 DataStore `lastPage == AI`；
3. `scenario.recreate()` 后：`ai_screen` 恢复、`tab_AI` 选中、消息内容/角色/顺序/`createdAt`/状态保持；`ai_input` 未聚焦、`imeVisible=false`；
4. 设置页执行清除 → 停留设置页提示“AI 会话已清除” → 返回 AI 页空态；
5. 再次重建：消息不恢复，`ai_empty_state` 可见；
6. tasks/projects 数量与内容（id/title、id/name）前后一致。

限制：未执行杀进程冷启动；未执行真实按键/软键盘弹出的人工确认。
