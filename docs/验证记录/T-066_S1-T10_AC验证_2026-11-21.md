**已通过**：默认页选择写入 DataStore；重建仓库后 `defaultPage`、`lastPage`、`predictiveBackEnabled` 保持。

**未达成**：
- `NavigationCoordinator` 的 `_activeTab` 固定初始化为 `AppTab.TODO`（`NavigationCoordinator.kt:37`），没有从 `UserSettings.defaultPage` 或 `lastPage` 初始化。
- `MainActivity` 只在设置页显示 `settings.defaultPage`（`MainActivity.kt:171`），未在启动时调用 `selectTab`/设置初始 tab；代码库没有 `setLastPage` 调用点。
- 因此 AC-N-14 的“设置改默认页后重启按新默认进入；再次打开恢复上次一级页”不能在当前实现上成立，尽管“设置值持久化”通过。
- 这不是测试错误；是 T-10 范围/实现缺口，需开发补应用启动映射，并由你确认是否纳入 T-10/T-11。

## 5. AC-N-21 预测返回：部分覆盖/未达成“上一页预览”

- `PredictiveBackCoordinator.shouldPreview` 只在 `page != null && canLeave` 时 true；`AppRoot` 仅在 `topFullScreen != null` 时组合 `PredictiveBackHandler`，半屏/选择器/新建面板/一级页不进入该分支。注册范围逻辑通过 JVM。
- **不足**：`AppRoot` 预览只对当前全屏内容做 `translationX = progress * 48dp`（`AppRoot.kt:66-73`），**没有渲染上一页/上一层内容**。AC-N-21 明确预期“松手前显示上一页/上一层预览”，因此当前实现只能算“内容位移提示”，**上一页预览未达成**。
- 开关关闭：`AppRoot` 条件为 `predictiveBackEnabled && shouldPreview(...)`；DataStore 开关持久化通过，但“关闭后不注册预览且返回结果不变”没有设备/可测注册 API 证据，列为未执行。
- 设备不支持/OEM 行为、系统手势与返回键一致性、无效字段抑制均未执行；不写通过。
